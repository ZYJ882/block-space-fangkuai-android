# 方块空间 / Block Space

**方块空间 / Block Space** 是一个使用 **Kotlin + Jetpack Compose** 实现的 Android 原生单机俄罗斯方块应用。项目采用完整的 Gradle Wrapper，能够直接导入 Android Studio；同时随交付提供已构建并验证的调试版 APK。

> 应用包名：`com.blockspace.tetris`
> 当前版本：`1.17.0`
> 最低 Android 版本：Android 8.0（API 26）

## 已实现功能

| 模块 | 内容 |
|---|---|
| 经典玩法 | 七种四格方块、碰撞检测、固定入栈与满行消除。默认使用标准 **7-Bag**（每袋七种各一个、洗牌后依次发放），并可切换为**真随机**（每次独立等概率抽取）。7-Bag 保证不会无限期缺少某一种方块；真随机则保留可能重复或长期缺块的传统体验。 |
| 操作 | 左移、右移、顺时针旋转、软降、硬降、暂停/继续与重新开始。软降每手动下落 1 格 +1 分，硬降每手动下落 1 格 +2 分；自动重力下落不计分。 |
| 游戏规则 | 采用现代竞赛计分：普通消行、T-Spin、B2B、连击封顶、全消奖励与独立落下分。普通模式按每 10 行升 1 级，采用现代 Marathon（Tetris Worlds / Guideline）重力曲线，并在第 15 级保持最高普通模式重力。玩家可在悠闲/标准/快速/极速（自动重力 ×0.75/×1.00/×1.25/×1.50）间切换。 |
| 游戏信息 | 实时展示得分、等级、消行数、**未来三个方块**、落点虚影，以及本次得分、B2B 与连击状态；得分区会显示当前自动下落速度和挑战分倍率。当前方块与预览从同一条刷新序列读取，预览顺序与实际出生顺序一致。 |
| 界面 | 蓝色竖屏游戏厅布局，棋盘尺寸同时受可用宽度与高度约束，顶部、侧边信息和底部操作区可完整显示。普通下落与横移采用短时平滑过渡；普通落地与直降均不绘制任何全棋盘闪光；仅在实际消行时展示低亮度局部行提示；得分数字滚动、得分事件淡入缩放。规则循环按下一次重力、锁定或直降保护到期时间唤醒；低重力阶段仅在方块实际移动或锁定时更新游戏界面，避免固定 16ms 轮询与无效整屏重组。应用进入后台时规则时钟会暂停，恢复前台后重新排程，后台停留时间不会误计入下落或锁定。 |
| 触控操作 | 底部采用无文字圆角矩形按钮；按钮按可用宽度自适应至 56–64dp 宽、54–58dp 高。长按灵敏度提供舒适（160/50ms）、快速（130/40ms）与竞技（120/33ms）一键预设；“高级灵敏度”可独立调整 DAS（100–220ms，每步 10ms）及 ARR（25–80ms，每步 5ms），实时显示并立即应用。全屏设置将长按灵敏度、下落速度、方块刷新逻辑与键位位置分区显示；刷新模式选择会立即保存，但严格从下一局开始生效。 |
| 启动体验 | 打开应用后先展示中英双语开始界面；点击“开始游戏”后，方块才会开始下落。 |
| 状态管理 | 游戏结束覆盖层、暂停覆盖层、一键重新开始，以及从顶部齿轮进入的全屏实时键位编辑模式。方块落地后保留 500ms 锁定延迟；落地后的有效移动或旋转最多可重置 15 次，确保高重力阶段仍可操作。上一块锁定后，新方块会获得 120ms 的直降误触保护，避免残留点击误直降；移动、旋转和软降不会被阻塞。动画只读取已完成的游戏状态并在渲染层插值，因此不会延迟碰撞、锁定、计分或触控判定；DAS/ARR 由独立的长按输入计时器触发，不依赖显示刷新率。 |
| 键位自定义 | 从顶部齿轮进入后，真实游戏界面保留为背景，实际按键会在其最终位置直接显示并可拖拽；不再使用缩略预览面板。按键仅能在棋盘下方的底部安全带内移动，位置按比例保存并适配不同屏幕。系统会夹紧边界，并要求按钮命中区域保留至少 8dp 间距；重叠或间距不足的拖拽会被拒绝，按键停留在上一个有效位置。 |
| 应用图标 | 原创扁平化 T 形方块启动图标，以深海军蓝、青蓝和琥珀色构成简约高辨识度图形，已提供完整 Android 多密度资源。 |

## 包名迁移说明

> 自 v1.13.0 起，应用包名从 `com.manus.tetris` 迁移为 **`com.blockspace.tetris`**。Android 会将其识别为新的应用标识；如设备上仍装有旧包名版本，请直接安装新 APK（两者可并存），或先卸载旧版后再安装以保持桌面与数据整洁。

## 在 Android Studio 中运行

使用 Android Studio 选择 **Open**，打开本项目根目录 `TetrisNative`。等待 Gradle 同步完成后，选择真实 Android 设备或模拟器，点击运行按钮即可。

| 配置项 | 设定 |
|---|---|
| 开发语言 | Kotlin |
| UI 框架 | Jetpack Compose / Material 3 |
| `compileSdk` / `targetSdk` | 35 / 35 |
| `minSdk` | 26 |
| Gradle Wrapper | 8.11.1 |
| Android Gradle Plugin | 8.7.3 |

## 安装 APK

将交付的 `TetrisNative-debug.apk` 传到 Android 设备后打开安装。若系统提示来源未知，请仅对您使用的文件管理器或浏览器授予一次“允许安装未知应用”权限。此文件为 **Debug 签名** 安装包，适合测试、侧载和内部体验；若要发布到应用商店，请在 Android Studio 中配置您自己的正式签名密钥并构建 Release 版本。

## 操作说明

| 按钮 | 效果 |
|---|---|
| 左移 / 右移 | 将当前方块向对应方向平移一格。 |
| 旋转 | 将当前方块顺时针旋转，并尝试进行基础墙踢修正。 |
| 下落 | 当前方块手动向下移动一格；每个成功移动固定 +1 分。落地时不会立即锁定，会进入 500ms 锁定延迟。 |
| 直落 | 当前方块直接落至可放置的最低位置并立即固定；每跨越 1 格固定 +2 分。上一块锁定后，新方块的前 120ms 会忽略直降输入，以吸收残留点击；其他操作立即可用。 |
| 速度与挑战分 | 在键位编辑界面选择悠闲/标准/快速/极速，自动重力分别为 ×0.75/×1.00/×1.25/×1.50。自动重力不计分；消行、T-Spin、B2B、连击和全消结算按同一倍率调整，软降和直降分不受影响。 |
| 方块刷新逻辑 | 在键位编辑界面选择 **7-Bag** 或 **真随机**。7-Bag 每一袋恰好包含七种方块各一个，适合公平挑战与规划；真随机每次独立抽取，可能连续重复或长期不出现某一种。选择立即保存，并只从下一局开始应用，不会改变当前预览队列。 |
| 暂停 | 暂停或恢复自动下落。 |
| 重开 | 清空棋盘和得分，开启新的对局。 |
