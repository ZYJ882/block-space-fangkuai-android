# 方块空间 / Block Space

**方块空间 / Block Space** 是一个使用 **Kotlin + Jetpack Compose** 实现的 Android 原生单机俄罗斯方块应用。项目采用完整的 Gradle Wrapper，能够直接导入 Android Studio；同时随交付提供已构建并验证的调试版 APK。

> 应用包名：`com.blockspace.tetris`
> 当前版本：`1.24.0`
> 最低 Android 版本：Android 8.0（API 26）

## 版本下载 / Releases

所有历史版本均已作为独立 GitHub Release 发布。每个发布页都包含对应版本的 `BlockSpace-v<版本号>-debug.apk`、固定到该版本源码提交的 Git 标签，以及中英双语更新说明。请从 [Releases 页面](https://github.com/ZYJ882/block-space-fangkuai-android/releases) 选择需要的版本；当前最新版为 [v1.24.0](https://github.com/ZYJ882/block-space-fangkuai-android/releases/tag/v1.24.0)。

> 所有安装包均为 **Android Debug 签名**，适用于测试、侧载和内部体验。若要发布到应用商店，请使用自己的正式签名密钥重新构建 Release 版本。

## 已实现功能

| 模块 | 内容 |
|---|---|
| 经典玩法 | 七种四格方块、碰撞检测、固定入栈与满行消除。默认使用标准 **7-Bag**（每袋七种各一个、洗牌后依次发放），并可切换为**真随机**（每次独立等概率抽取）。7-Bag 保证不会无限期缺少某一种方块；真随机则保留可能重复或长期缺块的传统体验。 |
| 操作 | 左移、右移、顺时针旋转、软降、硬降、暂停/继续与重新开始。软降每手动下落 1 格 +1 分，硬降每手动下落 1 格 +2 分；自动重力下落不计分。 |
| 游戏规则 | 采用现代竞赛计分：普通消行、T-Spin、B2B、连击封顶、全消奖励与独立落下分。普通模式按每 10 行升 1 级，采用现代 Marathon（Tetris Worlds / Guideline）重力曲线，并在第 15 级保持最高普通模式重力。玩家可在悠闲/标准/快速/极速（自动重力 ×0.75/×1.00/×1.25/×1.50）间切换。 |
| 游戏信息 | 实时展示得分、等级、消行数、**未来三个方块**、落点虚影，以及本次得分、B2B 与连击状态；得分区会显示当前自动下落速度和挑战分倍率。当前方块与预览从同一条刷新序列读取，预览顺序与实际出生顺序一致。 |
| 界面 | 蓝色竖屏游戏厅布局，棋盘尺寸同时受可用宽度与高度约束，顶部、侧边信息和底部操作区可完整显示。普通下落与横移采用短时平滑过渡；普通落地与直降均不绘制任何全棋盘闪光；仅在实际消行时展示低亮度局部行提示；得分数字滚动、得分事件淡入缩放。规则循环按下一次重力、锁定或直降保护到期时间唤醒；低重力阶段仅在方块实际移动或锁定时更新游戏界面，避免固定 16ms 轮询与无效整屏重组。应用进入后台时规则时钟会暂停，恢复前台后重新排程，后台停留时间不会误计入下落或锁定。 |
| 游戏音效 | 内置原创短 WAV 音效，覆盖开始、平移、旋转、软降、直降、锁定、普通消行、T-Spin/全消、暂停与游戏结束。采用 `SoundPool` 预载与游戏音频属性播放；移动和软降在长按时自动节流，避免音轨堆叠影响操作响应。全屏设置提供默认开启、可持久化的总开关。 |
| 局域网多人比赛 | v1.24.0 支持同一 Wi‑Fi 或手机热点下创建或搜索多人房间。每个房间最多 4 名玩家；创建者为房主，至少两人加入后可统一开始比赛。房间使用 Android NSD/mDNS 发现，房主仅中继已解析服务地址建立的本地 TCP 会话；无需账号、互联网、云端服务器或 IP 段扫描。创建房间时可选择两种锁定规则：默认**40 行竞速 / Race**不发送或应用灰色垃圾行，谁先安全消除 40 行谁赢本局；若在完成前堆顶则立即失败，即使当时消行更多也不例外。为防拖延，2 分 30 秒无人完成时，房主依次按消行数更多、棋盘总高度更低、分数更高裁决；三项完全相同则原局重赛且不计入 FT 胜场。可选**标准攻击 / Attack**以双消/三消/四消、T-Spin、B2B、连击和全消结算攻击，先抵消来袭攻击，余量经 220ms 延迟后以单孔灰色垃圾行进入目标棋盘；该模式维持真实堆顶即负。两种模式均采用 **FT3（先胜三局）**，并强制标准重力、7-Bag 和房主下发的固定比赛种子，确保双方刷新序列一致。任何来宾断线都会取消整场比赛而非直接判定胜者。 |
| 性能优化 | v1.20.0 起优化高频路径：旋转、移动、软降、直降、虚影和自动重力以直接坐标完成碰撞判定；清行与 T-Spin 消除临时集合；预览、当前方块与虚影绘制不再创建中间方块列表；棋盘快照与派生显示数据仅随游戏修订号重新生成。无效边界输入不会再触发规则循环重排或整屏重组，且游戏规则、计分与随机逻辑保持不变。 |
| 触控操作 | 底部采用无文字圆角矩形按钮；按钮按可用宽度自适应至 56–64dp 宽、54–58dp 高。长按灵敏度提供舒适（160/50ms）、快速（130/40ms）与竞技（120/33ms）一键预设；“高级灵敏度”可独立调整 DAS（100–220ms，每步 10ms）及 ARR（25–80ms，每步 5ms），实时显示并立即应用。v1.21.1 将长按改为基于系统原始触控生命周期的状态机：手指抬起、系统取消、多指主指针离开、按键禁用或组件销毁时都会立即取消连发协程，避免松手后继续横移。全屏设置将长按灵敏度、下落速度、方块刷新逻辑与键位位置分区显示；刷新模式选择会立即保存，但严格从下一局开始生效。 |
| 启动体验 | 打开应用后先展示中英双语开始界面；点击“开始游戏”后，方块才会开始下落。 |
| 状态管理 | 游戏结束覆盖层、暂停覆盖层、一键重新开始，以及从顶部齿轮进入的全屏实时键位编辑模式。v1.21.1 明确允许“再来一局”在游戏结束状态下执行重置，不再被普通游戏操作的结束保护拦截。方块落地后保留 500ms 锁定延迟；落地后的有效移动或旋转最多可重置 15 次，确保高重力阶段仍可操作。上一块锁定后，新方块会获得 120ms 的直降误触保护，避免残留点击误直降；移动、旋转和软降不会被阻塞。动画只读取已完成的游戏状态并在渲染层插值，因此不会延迟碰撞、锁定、计分或触控判定；DAS/ARR 由独立的长按输入计时器触发，不依赖显示刷新率。 |
| 键位自定义 | 从顶部齿轮进入后，真实游戏界面保留为背景，实际按键会在其最终位置直接显示并可拖拽；不再使用缩略预览面板。按键仅能在棋盘下方的底部安全带内移动，位置按比例保存并适配不同屏幕。系统会夹紧边界，并要求按钮命中区域保留至少 8dp 间距；重叠或间距不足的拖拽会被拒绝，按键停留在上一个有效位置。 |
| 应用图标 | 原创扁平化 T 形方块启动图标，以深海军蓝、青蓝和琥珀色构成简约高辨识度图形，已提供完整 Android 多密度资源。 |

## 操作说明

| 按钮 | 效果 |
|---|---|
| 左移 / 右移 | 将当前方块向对应方向平移一格。 |
| 旋转 | 将当前方块顺时针旋转，并尝试进行基础墙踢修正。 |
| 下落 | 当前方块手动向下移动一格；每个成功移动固定 +1 分。落地时不会立即锁定，会进入 500ms 锁定延迟。 |
| 直落 | 当前方块直接落至可放置的最低位置并立即固定；每跨越 1 格固定 +2 分。上一块锁定后，新方块的前 120ms 会忽略直降输入，以吸收残留点击；其他操作立即可用。 |
| 速度与挑战分 | 在键位编辑界面选择悠闲/标准/快速/极速，自动重力分别为 ×0.75/×1.00/×1.25/×1.50。自动重力不计分；消行、T-Spin、B2B、连击和全消结算按同一倍率调整，软降和直降分不受影响。 |
| 方块刷新逻辑 | 在键位编辑界面选择 **7-Bag** 或 **真随机**。7-Bag 每一袋恰好包含七种方块各一个，适合公平挑战与规划；真随机每次独立抽取，可能连续重复或长期不出现某一种。选择立即保存，并只从下一局开始应用，不会改变当前预览队列。 |
| 游戏音效 | 在键位编辑界面的“游戏音效”分区开启或关闭。设置立即保存；关闭后不会再播放移动、旋转、下落、消行、暂停或结束提示音。 |
| 局域网多人比赛 | 最多 4 台设备先连接到同一 Wi‑Fi 或同一手机热点，然后在开始页或顶部“⌁”按钮进入局域网比赛。房主可创建默认的**40 行竞速**或可选的**标准攻击**房间；其他玩家刷新后加入。所有多人对局强制标准重力、7-Bag，并由房主下发固定种子。两种房间均采用 FT3（先胜三局）。Race 无灰色垃圾行，先安全消除 40 行者赢；完成前堆顶即输，不按分数翻盘。到 2 分 30 秒仍无人完成时，依次按消行数、较低堆高、较高分数裁决；完全相同则重赛。Attack 在消行后按攻击表结算，优先抵消本方待进入攻击；未抵消部分在 220ms 后以单孔灰色垃圾行进入目标棋盘，真实堆顶即输。开局后主棋盘缩小，右侧以紧凑卡片显示对手的棋盘、得分、消行、当前下落方块、虚影、堆叠和淘汰状态。一名来宾断线会取消整场比赛并提示重新建房或加入，而不会自动判定另一方获胜。当前 targetSdk 为 35；未来升级至 Android targetSdk 37 时需按 Android 官方本地网络权限要求增加运行时授权。 |
| 暂停 | 暂停或恢复自动下落。 |
| 重开 | 清空棋盘和得分，开启新的对局。 |
