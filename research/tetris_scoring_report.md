# 俄罗斯方块经典与现代计分规则对照

**作者：Manus AI**  
**研究范围：** 经典 BPS、Nintendo（NES / Game Boy）、Sega、现代 Guideline 兼容游戏、Tetris Effect 与 Tetris 99。  

> **结论先行：** “经典俄罗斯方块计分”并不是一套唯一公式。最常被称为经典的 NES / Game Boy 体系使用 **40 / 100 / 300 / 1200** 的消行基础分，并以 `(等级 + 1)` 放大；而许多现代作品采用 **100 / 300 / 500 / 800 × 等级**，并叠加 T-Spin、Back-to-Back、连击、全消和落下距离奖励。[1] [2]

## 1. 术语与比较口径

本文中的 **单消、双消、三消、四消**，分别指一次锁定后清除 1、2、3、4 行；其中四消通常被称为 **Tetris**。`等级` 的计算时点很关键：有的游戏按本次消行**之前**的等级计算，有的则按消行**之后**的等级计算。两者都可能被称作“经典规则”，但分数会不同。[1]

| 术语 | 含义 | 作用 |
|---|---|---|
| Soft drop / 软降 | 玩家主动让方块加速下落 | 通常按格数奖励，或不奖励 |
| Hard drop / 直降 | 将方块立即落到底部 | 现代作品常按格数奖励 |
| T-Spin | 通过旋转 T 形方块完成锁定/消行 | 现代技术动作奖励 |
| Back-to-Back（B2B） | 连续完成“四消”或符合条件的 T-Spin | 现代作品的连续困难动作奖励 |
| Combo / 连击 | 连续若干次锁定都发生消行 | 奖励持续消行 |
| Perfect Clear / 全消 | 锁定并消行后棋盘完全清空 | 常见高额附加奖励 |

## 2. 主要计分体系

### 2.1 1988 BPS / Famicom 早期体系

1988 年 BPS 版本及 Famicom 版使用较朴素的固定消行分：单消 40、双消 100、三消 300、四消 1200。该体系的核心是让四消的单位行收益明显高于其他消行；该表本身不乘等级。若方块以直降方式落下，会额外获得“直降跨越行数 + 1”的分数。[1]

| 一次消行数 | 基础分 | 每条消除行的平均分 |
|---:|---:|---:|
| 1 | 40 | 40 |
| 2 | 100 | 50 |
| 3 | 300 | 100 |
| 4（Tetris） | 1200 | 300 |

这种结构非常适合复古单机高分玩法：它显著鼓励玩家留出一列，等待 I 方块完成四消，而不是频繁拆掉棋面。

### 2.2 Nintendo：NES / Game Boy 经典体系

Nintendo 体系以 BPS 的 40 / 100 / 300 / 1200 为基础，并乘以 `(等级 + 1)`。因此在 0 级，四消为 1200 分；在 9 级，四消为 12000 分。软降通常按连续软降的格数计分，且不随等级放大；不过 NES 和 Game Boy 都有“只计入导致锁定的最后一次软降”这一版本特性，NES 还存在软降 BCD 加法缺陷。[1] [2]

| 消行类型 | 公式 | 0 级示例 | 9 级示例 |
|---|---|---:|---:|
| 单消 | `40 × (等级 + 1)` | 40 | 400 |
| 双消 | `100 × (等级 + 1)` | 100 | 1,000 |
| 三消 | `300 × (等级 + 1)` | 300 | 3,000 |
| 四消 | `1200 × (等级 + 1)` | 1,200 | 12,000 |
| 软降 | 每格 1 分，通常不乘等级 | 依距离而定 | 依距离而定 |

> 如需“手感像 NES”，应采用此表并以四消作为高分核心；如需逐字节复刻 NES，则还要复制其软降计数与等级取值时点等历史特性，而非只复制分数表。[1]

### 2.3 Sega 街机体系

早期 Sega 体系按等级段直接采用不同的分数表。例如 0–1 级为 100 / 400 / 900 / 2000，8 级及以上为 500 / 2000 / 4500 / 10000；软降每行分数也随等级段从 1 提升到 5。若某次消行同时形成全消，已得分数再乘以 10。[1]

| 等级段 | 单消 | 双消 | 三消 | 四消 | 软降每行 |
|---|---:|---:|---:|---:|---:|
| 0–1 | 100 | 400 | 900 | 2,000 | 1 |
| 2–3 | 200 | 800 | 1,800 | 4,000 | 2 |
| 4–5 | 300 | 1,200 | 2,700 | 6,000 | 3 |
| 6–7 | 400 | 1,600 | 3,600 | 8,000 | 4 |
| 8+ | 500 | 2,000 | 4,500 | 10,000 | 5 |

Sega 的特点是“等级越高，所有动作都更值钱”，并通过 10 倍全消奖励制造更强的残局目标。

### 2.4 现代 Guideline 兼容体系

许多 Tetris DS 之后的 Guideline 兼容游戏采用下表的核心结构。普通消行基础分为单消 100、双消 300、三消 500、四消 800，均乘以消行前等级；软降每格 1 分，直降每格 2 分。与复古体系最大的差异，是它会有意识地奖励 T-Spin、B2B、连击和全消，使“旋转技巧、持续攻击和棋盘清空”都成为可见的得分路径。[1]

| 动作 | 基础分公式 |
|---|---:|
| 单消 / 双消 / 三消 / 四消 | `100 / 300 / 500 / 800 × 等级` |
| Mini T-Spin 0 行 / T-Spin 0 行 | `100 / 400 × 等级` |
| Mini T-Spin 单消 / T-Spin 单消 | `200 / 800 × 等级` |
| T-Spin 双消 / 三消 | `1200 / 1600 × 等级` |
| B2B 困难消行 | 该动作的消行基础分 × `1.5` |
| 连击 | `50 × 连击计数 × 等级` |
| 软降 / 直降 | 每格 `1 / 2` 分 |

在若干现代 Guideline 游戏中，全消还另加：单行 800×等级、双行 1200×等级、三行 1800×等级、四消全消 2000×等级；B2B 四消全消为 3200×等级。该全消奖励需要再加到本次普通消行分上，而不是替代普通消行分。[1]

### 2.5 Tetris Effect：Zone 特殊状态体系

Tetris Effect 保留了常规消行得分，但其 Zone 机制允许临时停止堆叠并累积超过四行的超大消行。Zone 内每完成一次 8 行或以上的 Octoris，会增加 `+1×` 倍率；满能量（20 秒）进入 Zone 另加 `+1×`，最高可达 3 倍。Zone 结束时，除结算期间消行分外，还会按 Zone 内每消一行额外给 100 分。[3]

| Zone 名称 | 一次累计消行数 |
|---|---:|
| Tetris | 4–7 |
| Octoris | 8–11 |
| Dodecatris | 12–15 |
| Ultimatris | 20 |
| WTFtris | 25+ |

这是一类“状态爆发”计分设计：基本分并不是唯一目标，玩家还需要管理 Zone 资源，并在进入状态后尽可能搭出更大的累计消行。

### 2.6 Tetris 99：攻击行而非传统高分

Tetris 99 的核心对战资源不是单机分数，而是对对手发送的垃圾行。普通单消不发送攻击行，双消、三消、四消分别发送 1、2、4 行；T-Spin 单消、双消、三消分别发送 2、4、6 行。B2B 额外加 1 行，全消额外加 4 行；连击也按照连击数增加攻击行。[4]

| 动作 | 基础攻击行 |
|---|---:|
| 单消 / 双消 / 三消 / 四消 | 0 / 1 / 2 / 4 |
| T-Spin 单消 / 双消 / 三消 | 2 / 4 / 6 |
| B2B | `+1` |
| 全消 | `+4` |
| 连击 1 / 3 / 5 / 10 | `+1 / +2 / +3 / +5` |

此外，徽章可带来 25%、50%、75%、100% 的攻击加成；结算顺序是先汇总动作攻击行，再叠加多人攻击者加成，最后应用徽章加成并向下取整。[4] 这类规则适合 PvP，但不应直接当作单机“得分”公式，因为它服务的是对局压力、垃圾行抵消和目标选择。

## 3. 如何选择规则

| 目标体验 | 推荐体系 | 原因 |
|---|---|---|
| 复古、易理解、四消导向 | Nintendo 经典 | 一张简单分表，四消价值突出，符合大众对老式俄罗斯方块的印象。 |
| 现代技术与高分深度 | Guideline | T-Spin、B2B、连击、全消共同提供多条进阶得分路径。 |
| 街机高等级风险回报 | Sega | 所有分数随等级段强化，全消奖励醒目。 |
| 视觉化爆发、章节挑战 | Zone 型 | 通过资源条、倍率与超大消行制造短时间决策高潮。 |
| 实时竞技 | 攻击行体系 | 优先衡量攻击、抵消与击杀，而不是仅比较累计分。 |

## 4. 对“方块空间 / Block Space”当前实现的建议

当前项目的普通消行已经使用 `100 / 300 / 500 / 800 × 等级`，并对软降和直降分别按每格 `1 / 2` 分计分；因此它的基础方向更接近现代 Guideline，而不是 Nintendo 经典体系。[1]

若目标是做一款易上手、又有长期刷分空间的单机游戏，建议保留现有基础表，并补全以下四项。首先，对四消和完整 T-Spin 消行加入 B2B `×1.5`。其次，对连续消行加入 `50 × 连击计数 × 等级`。然后，为全消追加奖励。最后在 HUD 中展示“B2B”和“连击”提示，以把玩家的技术动作和可见反馈连接起来。[1]

若目标是强调“经典味道”，则应将普通消行改为 Nintendo 的 `40 / 100 / 300 / 1200 × (等级 + 1)`，关闭 T-Spin、B2B、连击和全消额外分，并仅保留简洁的软降计分。两种模式可以通过“经典计分 / 现代计分”开关并存，从而避免把不同年代的规则混为一谈。
