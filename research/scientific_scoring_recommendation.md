# 面向单机与竞赛扩展的俄罗斯方块科学计分方案

**作者：Manus AI**  

> **推荐结论：** 对于“方块空间 / Block Space”这类单机高分游戏，最合理的方案不是纯 CTWC 复古分表，也不是无上限叠加的花式奖励，而是采用 **现代 Guideline 的消行基线 + 有上限的 B2B / 连击 / 全消奖励 + 与等级解耦的落下分**。这能同时实现易理解、奖励技术、限制刷分，并保留未来赛事模式的可比性。[1]

## 1. “科学”在计分设计中的含义

计分规则不存在放之四海而皆准的数学最优解，因此“最科学”应理解为一套可检验的设计目标。优秀规则应让更困难、更稀缺、更有风险的动作产生更高期望收益，同时避免低风险重复操作、拖延时间或单一套路压倒所有选择。玩家应能在观察 HUD 时理解为什么得分增加，赛事方也应能用同一规则稳定比较不同对局。

| 目标 | 规则要求 | 本方案的对应设计 |
|---|---|---|
| 可理解性 | 基础分表可在数秒内读懂 | 普通消行只有四个档位：100 / 300 / 500 / 800 |
| 技巧表达 | 旋转、连续困难消行、全消应有额外价值 | T-Spin、B2B、连击、全消为独立可见奖励 |
| 风险回报 | 高收益动作需要更高堆叠或更窄容错 | 四消、T-Spin Double、全消的收益显著高于普通单消 |
| 抗刷分 | 不能靠无风险软降或拖时间大量取分 | 落下分不乘等级，且远低于消行主分 |
| 可竞赛性 | 规则确定、无随机加分、可复算 | 所有得分来自锁定时可验证的棋盘事件 |

## 2. 推荐的核心公式

设 `L` 为本次锁定前的等级，且 `L ≥ 1`。设 `Base(action)` 为动作基础分，`B2B` 为连续困难动作状态，`Combo` 为本次连击编号。一次锁定的总分定义为：

```text
总分 = 基础消行分 × B2B 倍数 + 连击分 + 全消奖励 + 落下分
```

其中，**仅基础消行分**进入 B2B 倍数，落下分不进入任何倍数。这一边界能避免玩家因无意义的长距离落下而获得不成比例的收益。

### 2.1 基础消行分

| 动作 | `Base(action)` | 本次基础消行分 |
|---|---:|---:|
| 单消 | 100 | `100 × L` |
| 双消 | 300 | `300 × L` |
| 三消 | 500 | `500 × L` |
| 四消（Tetris） | 800 | `800 × L` |
| T-Spin 0 行 | 400 | `400 × L` |
| T-Spin 单消 | 800 | `800 × L` |
| T-Spin 双消 | 1200 | `1200 × L` |
| T-Spin 三消 | 1600 | `1600 × L` |

这套基线与近期 Guideline 兼容游戏的广泛做法一致：普通消行采用 100 / 300 / 500 / 800 × 等级，并为 T-Spin 提供更高价值。[1] 为减少规则学习成本，建议第一版不单独设置 Mini T-Spin 分支；检测到标准“三角占位”的 T-Spin 后按完整 T-Spin 计分即可。之后如需要向硬核社区扩展，再添加 Mini 规则。

### 2.2 B2B：困难动作连续奖励

将 **四消、T-Spin 单消、T-Spin 双消、T-Spin 三消**定义为“困难消行”。如果本次和上一次可计入连锁的动作都属于困难消行，则：

```text
B2B 倍数 = 1.5
否则 B2B 倍数 = 1.0
```

普通单消、双消或三消会中断 B2B；没有消行的锁定不应中断 B2B。`×1.5` 是现代 Guideline 中的典型力度：能让持续完成难动作变得重要，但不会使其完全碾压其他策略。[1]

### 2.3 连击：奖励连续清线，但设置上限

只要连续锁定都发生至少一次消行，连击延续；第一次消行的 `Combo = 0`，第二次连续消行的 `Combo = 1`。推荐：

```text
连击分 = min(50 × Combo × L, 400 × L)
```

也就是说，连击增长到第 8 档后封顶。封顶是本方案相对原始 Guideline 的关键改造：Guideline 常用 `50 × Combo × L`，但不设上限时，某些安全的单消连击堆叠会过度主导高分策略。[1] 以 `400 × L` 封顶后，连击仍有价值，却不会超过一次困难 T-Spin 或四消的主导地位。

### 2.4 全消：高难残局的明确目标

当本次锁定与消行后棋盘为空时，在普通消行分之外增加：

| 全消类型 | 附加分 |
|---|---:|
| 单消全消 | `800 × L` |
| 双消全消 | `1200 × L` |
| 三消全消 | `1800 × L` |
| 四消全消 | `2000 × L` |
| B2B 四消全消 | `3200 × L` |

这些数值来自若干近期 Guideline 游戏使用的全消附加分表。必须注意：全消奖励应当**叠加**普通消行分，而不是替代普通消行分。[1]

### 2.5 落下分：即时反馈但不左右胜负

| 操作 | 建议奖励 |
|---|---:|
| 软降 | 每格 1 分 |
| 直降 | 每格 2 分 |

落下分**不乘等级、不计入 B2B、不计入连击、也不参与全消倍数**。这与现代 Guideline 的常见口径一致。[1] 这样直降会更顺手、更有反馈，但不会因为后期等级膨胀而比消行本身更重要。

## 3. 示例计算

假设玩家在等级 `L = 4` 时，完成一次 B2B T-Spin Double，处于第 3 档连击，并直降 12 格；棋盘没有全消。

| 组成 | 公式 | 分数 |
|---|---|---:|
| T-Spin Double 基础分 | `1200 × 4` | 4,800 |
| B2B 加成后的消行分 | `4,800 × 1.5` | 7,200 |
| 第 3 档连击 | `50 × 3 × 4` | 600 |
| 直降 12 格 | `2 × 12` | 24 |
| **本次总分** | `7,200 + 600 + 24` | **7,824** |

同一等级的一次普通四消为 `800 × 4 = 3,200` 分；B2B 四消为 `3,200 × 1.5 = 4,800` 分。这个相对比例让四消始终很强，又让高质量 T-Spin Double 因技巧门槛获得合理优势。

## 4. 与 CTWC 经典规则的关系

CTWC 采用 8-bit Nintendo Tetris，核心消行分是 `40 / 100 / 300 / 1200 × (等级 + 1)`，以四消高分为中心，并不使用现代 T-Spin、B2B、连击或全消附加分。[2] 该体系极其适合复古赛事和高分生存，但它刻意不奖励现代旋转技术。

因此，推荐将产品做成两个明确模式：

| 模式 | 适用场景 | 计分规则 |
|---|---|---|
| 现代竞赛 / 默认模式 | 单机日常、高分榜、现代操作 | 本文推荐方案 |
| 经典 CTWC 模式 | 复古训练、传统赛事复刻 | Nintendo `40 / 100 / 300 / 1200 × (L+1)`，关闭技术加分 |

## 5. 实施顺序

第一阶段先实现普通消行、软降、直降和 B2B；第二阶段加入标准 T-Spin 检测和全消判断；第三阶段加入连击上限与 HUD 反馈。HUD 至少应显示“分数变化”、“B2B”、“连击 ×N”和“全消”，否则玩家难以学习规则，也难以验证得分来源。

不建议把广告、随机道具、观看时长或付费行为纳入分数。它们会降低同局可比性，破坏高分榜和潜在比赛的可信度。
