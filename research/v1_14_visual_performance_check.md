# v1.14.0 视觉与性能检查记录

## 检查范围

本次检查覆盖了 `com.blockspace.tetris` v1.14.0 调试 APK 的安装包元数据、签名、游戏循环、棋盘 Canvas 覆盖层与单元测试结果。重点关注普通落地/直降时的视觉闪烁，以及低重力阶段的无效界面刷新。

| 检查项 | 结果 |
|---|---|
| APK 包名 | 通过：`com.blockspace.tetris` |
| APK 签名 | 通过：Android Debug APK Signature Scheme v2 |
| 单元测试 | 通过：18 项，0 失败，0 错误 |
| 普通落地覆盖层 | 已移除：不再存在锁定脉冲、直降全棋盘色层或 `hardDropFlash` 路径 |
| 消行反馈 | 保留：只针对实际清除的行，白色透明度降至 20%，金色扫线透明度降至 46% |
| 空帧重组 | 已优化：低重力阶段仅在方块实际移动或锁定时增加 UI revision |

## 已修复的风险点

旧循环会每 16ms 调用 `revision++`，即使重力累计尚不足以让方块移动，也会导致整个 Compose 游戏界面重新读取棋盘、幽灵块、预览和信息面板。v1.14.0 将 `TetrisGame.advanceTime` 改为返回是否发生可见游戏状态变化；界面只在返回 `true` 时刷新。对应测试验证了 16ms 空帧不会请求重绘，而自动下落和锁定仍会请求重绘。

棋盘 Canvas 已不存在普通落地、直降时的全棋盘矩形覆盖层。只有 `clearRevision` 在实际消行时触发低亮度的局部行反馈。

## 运行时限制

检查环境未连接 Android 实机或模拟器，因此无法采集真机 GPU 帧时间、Jank 百分比或 Android Studio System Trace。APK 构建、规则测试、静态渲染路径检查和签名校验均已完成。建议在目标设备上连续体验普通速度与极速速度各数分钟；若仍出现卡顿，可提供发生场景（速度档位、是否消行、是否长按），以便进行针对性帧分析。
